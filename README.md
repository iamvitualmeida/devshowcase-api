## Sobre o projeto

A DevShowcase API é uma API REST desenvolvida em Java 17 e Spring Boot 4.0.8 como parte da Tarefa 1 da atividade DevShowcase. O projeto permite o cadastro e a consulta de perfis de desenvolvedores, projetos e tecnologias utilizadas. A aplicação utiliza PostgreSQL para armazenamento dos dados, com Spring Data JPA e Hibernate para a persistência. O sistema possui as entidades Profile, Project, Technology e Feedback, com relacionamentos entre perfis, projetos, tecnologias e feedbacks. A estrutura da aplicação foi organizada em camadas, utilizando Controllers, Services, Repositories, Entities e DTOs, facilitando a organização e manutenção do código. Também foram implementadas validações dos dados recebidos e um tratamento global de erros. Os principais endpoints permitem criar e consultar perfis, cadastrar e listar tecnologias e criar e listar projetos. A API foi testada utilizando o Postman e está disponível para execução local na porta 8080.
